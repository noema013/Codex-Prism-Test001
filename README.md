# Codex Prism

A 60-second interactive browser demo game designed for Galaxy Z Fold presentation use.

## Play

Open `index.html` directly from GitHub Pages.

Presentation auto-demo mode:

```text
?demo=auto&time=60
```

## Local preview

```bash
npm start
```

Then open:

```text
http://localhost:4173/index.html?demo=auto&time=60
```
