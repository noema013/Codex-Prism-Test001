# Lofi-12 やさしいガイド

Galaxy Z Fold 7のカバー画面を含むAndroidスマートフォン向けに作った、インストール可能なWebアプリ（PWA）です。公式「LIVEN Lofi-12 User's Manual Rev.3」の内容を、音楽制作や機器操作に不慣れな方向けの短い手順に組み直しています。

## できること

- 日本語の音声または文字で「やりたいこと」を検索
- 実機図上で使うボタン・ノブを番号表示
- 1操作ずつ確認できるチェックリスト
- 音楽制作の用語集
- 最近見たガイドと進み具合の端末内保存
- ホーム画面への追加と、文字ガイドのオフライン閲覧

現在は、リアルタイム録音、ステップ入力、サンプル録音／編集、音選び、パターン再生／保存、テンポ、エフェクト、消去、チョップの12ガイドを収録しています。

## ローカルで確認する

このフォルダーをローカルWebサーバーで配信し、`http://localhost:4173` などのURLをChromeで開きます。ファイルを直接開く方法では、音声入力やオフライン保存が正しく動かない場合があります。

## Androidへインストールする

1. このフォルダーをHTTPS対応のWebサーバーへ配置します。
2. GalaxyのChromeで公開URLを開きます。
3. Chromeメニューの「ホーム画面に追加」またはアプリ内のインストールボタンを選びます。

音声認識はAndroid／Chromeの機能を利用します。端末の音声認識設定や言語パックによっては、音声入力時に通信が必要です。文字検索と一度読み込んだガイドはオフラインでも使えます。

## 主なファイル

- `index.html` - アプリの土台
- `styles.css` - カバー画面向けのレイアウトと見た目
- `app.js` - ガイド内容、検索、音声入力、画面操作
- `manifest.webmanifest` / `sw.js` - インストールとオフライン対応
- `assets/manual/` - 提供された公式マニュアルから抽出した実機図
